# OCR Service

**Version 0.1**

A simple FastAPI service for extracting text from images using OpenCV and Tesseract OCR.

Created for practicing DevOps skills.

## Stack

* Python
* FastAPI
* OpenCV
* Tesseract OCR
* Pytest

## API

* `POST /ocr` - extract text from an image
* `GET /health` - health check

## Tests

```bash
python -m pytest
```
